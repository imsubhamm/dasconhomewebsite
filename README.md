# Dascon Sourav Commercial

Modern marketing website for **Dascon Sourav Commercial Pvt. Ltd.** — a Kolkata-based construction service provider.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- Framer Motion

## Local development

```bash
npm install
npm run dev
```

The dev server runs at **http://127.0.0.1:4827**.

## Production build

```bash
npm run build
npm run preview
```

Preview also serves on port **4827**.

## Sections

- Hero — brand-led first viewport with full-bleed construction imagery
- About — company profile, GST, IEC, ownership
- Services — commercial, residential, industrial, hospitality, retail, institutional, materials
- Why Dascon / Process — delivery approach
- Contact — inquiry form (opens mailto) and registered office details

## Notes

- Domain is not final; the UI uses the brand name only (no invented live domain).
- Company facts: MCA / ZaubaCorp filings (CIN, directors, registered office,
  incorporation) plus IndiaMART for GST, IEC, and marketed construction services.
